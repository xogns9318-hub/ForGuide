# 일자리 목록 외부 사이트 조사

확인일: **2026-10-21**

## 작성 원칙

- 공공·공식 사이트를 먼저 사용한다. 민간 플랫폼은 외국인 대상 기능이 공식 사이트에서 확인된 경우에만 포함한다.
- 체류자격, 지원 언어, 모집 조건은 사이트·프로그램·채용 공고마다 달라질 수 있다. 이 문서에서 확인하지 못한 값은 화면에 **`확인 필요`**로 표시한다.
- 외부 사이트의 운영 상태와 조건은 바뀔 수 있으므로, 배포 전에 다시 확인한다.
