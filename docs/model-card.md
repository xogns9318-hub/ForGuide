## 월 상환액·총 이자 계산기

- 월 상환액 경로: /service/monthlyPayment
- 총 이자 경로: /service/totalInterest
- 두 페이지는 LoanCalculator 컴포넌트를 사용한다.
- 계산 함수는 frontend/src/utils/loanCalculator.js에서 공통 관리한다.
- 기존 공통 헤더·푸터와 본문 너비를 사용한다.

### 입력 항목

| 항목 | 타입 | 단위 | 허용 범위 |
| --- | --- | --- | --- |
| 대출금액 | 정수 | 만원 | 입력 0~999999999999, 계산 시 0 초과 |
| 연 금리 | 숫자, 소수점 한 자리 | % | 0~20 |
| 상환 기간 | 정수 | 개월 | 입력 0~600, 계산 시 0 초과 |
| 거치 기간 | 정수 | 개월 | 0~600, 상환 기간 미만 |

위 범위는 사용자가 지정한 입력 제한이며 실제 상품 조건이 아니다.

- 잘못된 형식이나 범위 초과 입력은 반영하지 않는다.
- 숫자 입력 제한 경고문은 표시하지 않는다.
- 거치 기간이 상환 기간 이상이면 환산 문구 대신 아래 경고를 표시한다.
  "거치 기간은 상환 기간보다 짧게 입력해야 합니다."
- 관계 오류나 필수값 누락 시 계산 버튼을 비활성화한다.

### 기간 기준

- 총 대출기간 = 상환 기간 + 거치 기간.
- 예: 상환 24개월 + 거치 6개월 = 총 30개월.
- 거치 기간에는 이자만 납부한다.
- 거치 이후 입력한 상환 기간 동안 원금을 상환한다.
- 만기일시는 총 대출기간 마지막 회차에 원금을 상환한다.

### 계산 기준

- 월 금리는 연 금리를 12로 나눈 값이다.
- 매월 이자는 회차 시작 원금 잔액을 기준으로 계산한다.
- 매월 이자는 원 미만 버림한다.
- 원금균등의 분할 원금과 원리금균등의 기준 납입액도 원 미만 버림한다.
- 남은 원금은 마지막 회차에 정산한다.
- 금리 0%를 지원한다.
- 수수료는 제외한다.
- 총이자와 총상환액은 월별 표의 금액과 일치한다.
- 첫 달 상환 금액은 거치 회차를 포함한 첫 회차 납입액이다.
- 큰 원 단위 금액은 BigInt로 계산하고 문자열로 반환한다.

### 화면 동작

- 계산 전 결과 요약·그래프·월별 상환표는 표시하지 않는다.
- 입력 영역의 상환 방식 선택창은 사용하지 않는다.
- 계산하기를 누르면 공통 함수로 세 방식의 결과를 생성한다.
- 입력값이 바뀌면 이전 계산 결과를 지운다.
- 숫자 입력 시 불필요한 앞자리 0을 즉시 제거한다.
- 단독 0과 금리의 0.5 같은 소수 표기는 유지한다.
- 왼쪽에는 입력 영역과 그 아래 그래프를 배치한다.
- 오른쪽에는 결과 요약과 그 바로 아래 월별 상환표를 배치한다.
- 오른쪽 전체 높이는 왼쪽 입력 영역과 그래프의 전체 높이에 맞춘다.
- 상환 방식에 따라 요약 높이가 바뀌면 상환표가 남은 높이를 채운다.
- 결과 표와 비교 카드는 흰색 배경을 사용한다.
- 두 계산기 상단에 routeConfig.js의 제목과 설명을 사용하는 공통 배너를 표시한다.

### 월 상환액 결과

- 결과 영역 상단에서 원리금 균등·원금 균등·만기 일시를 선택한다.
- 선택한 방식의 요약을 오른쪽 위에 표시한다.
- 선택한 방식의 그래프를 왼쪽 아래에 표시한다.
- 선택한 방식의 월별 상환표를 오른쪽 아래에 표시한다.
- 표 열 순서는 회차·납입 원금·이자·납입 원금 합계·잔금이다.
- 납입 원금 합계는 해당 회차까지의 누적 원금이다.
- 잔금은 대출원금에서 누적 납입 원금을 뺀 값이다.
- 마지막 회차의 잔금은 0원이다.
- 모든 표 행 높이를 통일한다.
- 긴 표는 표 영역 안에서 스크롤한다.

### 총 이자 결과

- 입력은 대출금액·연 금리·상환 기간·거치 기간이다.
- 월 상환액 계산기와 같은 상환 방식 탭과 결과 요약을 사용한다.
- 원리금 균등·원금 균등·만기 일시를 선택한다.
- 선택한 방식의 총 갚을 금액·총 이자 금액·첫 달 상환 금액을 표시한다.
- 선택한 방식에 따라 그래프와 월별 상환표가 함께 바뀐다.
- 총이자는 공통 함수가 계산한 월별 이자의 합이다.
- 총상환액은 대출원금과 총이자의 합이다.

### 그래프

- 두 계산기는 같은 월별 선 그래프를 사용한다.
- 선택한 방식의 납입 원금·이자·납입액을 표시한다.
- 배경 점선과 그래프 아래 범례는 표시하지 않는다.
- 축의 눈금선과 테두리는 표시하지 않는다.
- 마우스를 올리면 회차와 세 항목의 정확한 금액을 표시한다.
- 그래프 좌표는 만원 단위의 표시용 숫자다.
- 정확한 원 단위 금액은 표와 툴팁에서 확인한다.
- 그래프 애니메이션은 사용하지 않는다.

## 미결정 사항

- 추천 모델의 입력·출력·학습 데이터·평가 방법
- 실제 조회와 공통 상태 화면의 연결
- 실제 빈 결과의 조건 변경 동작
- 실제 조회 재시도 함수
- 실제 서비스 결과의 예시 표시·마스킹 적용 위치
- 상품별 일수 계산·수수료·실제 납부일 조건
- 큰 금액의 서버·DB 저장 타입과 범위

## 공통 헤더

- 헤더는 기존 공통 본문 너비를 사용한다.
- 첫 번째 줄에는 왼쪽 로고와 오른쪽 회원 메뉴·언어 선택창을 표시한다.
- 두 번째 줄에는 카테고리를 동일한 너비의 6칸으로 표시한다.
- 번역 문구가 길어져도 카테고리 칸의 너비와 높이는 유지한다.
- 긴 카테고리 문구는 해당 칸 안에서 줄바꿈한다.
- 언어 선택창은 기존 공통 SelectBox를 사용한다.
- 선택창을 다시 클릭하면 목록을 닫고 마우스 강조를 해제한다.
- 선택창 강조선은 기존 테두리에 붙여 표시한다.
- 키보드 조작에서는 포커스 표시를 유지한다.
- 언어 변경과 localStorage 저장 동작을 유지한다.
- 카테고리 강조 배경은 칸 안쪽에 여백을 두고 둥글게 표시한다.
- 세부 메뉴는 카테고리 중심에 맞추고 내부 글씨를 가운데 정렬한다.
- 카테고리와 세부 메뉴 사이 간격은 6px이다.
- 세부 메뉴는 마우스를 올린 항목 하나만 강조하며, 마우스를 떼면 현재 페이지 항목을 다시 강조한다.

### 작은 화면의 헤더

- 화면 너비 1024px 이하에서 햄버거 메뉴로 전환한다.
- 닫힌 상태에서는 로고와 메뉴 버튼만 표시한다.
- 메뉴 버튼을 누르면 헤더 아래에 세로 카테고리 목록을 표시한다.
- 열린 상태에서는 메뉴 버튼을 닫기 아이콘으로 표시한다.
- 세부 기능이 있는 카테고리는 클릭으로 펼치거나 닫는다.
- 한 번에 한 카테고리만 펼친다.
- 펼친 목록에는 주 기능 안내 링크와 세부 기능 링크를 표시한다.
- 회원 메뉴와 언어 선택은 펼친 메뉴 아래에 표시한다.
- 메뉴가 열린 동안 본문 스크롤을 막고 메뉴 내부에서 스크롤한다.
- 링크 선택·닫기 버튼·Escape로 전체 메뉴를 닫는다.
- 주소나 화면 크기 구간이 바뀌면 메뉴 상태를 초기화한다.
- 넓은 화면의 기존 헤더 배치를 유지한다.
- 메뉴 아래의 회원 링크와 언어 선택은 각 줄에서 가운데 정렬한다.
