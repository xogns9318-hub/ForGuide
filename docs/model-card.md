## 공통 상태 화면

헤더·푸터 없이 공통 배경의 중앙에 아이콘과 문구를 표시한다.

- 로딩: 회전하는 모래시계와 대기 문구
- 빈 결과: 빈 목록 안내
- 실패·재시도: X 표시, 실패 안내와 재시도 버튼
- 입력 검증: 입력 항목 아래 오류 표시
- 예시 표시: 예시 데이터·예시값 배지
- 마스킹: 가상 이름·계좌번호를 일부 가려 표시
- 잘못된 접근: X 표시와 오류 문구

입력 검증 화면은 필수 입력을 확인하는 표시 초안이다.
실제 서비스 입력 항목과 검증 범위는 미정이다.

## 회원가입 화면 (`/signup`)

모델 화면은 아니며, 인증 흐름의 첫 화면이다. 경로·입력 항목은 Figma "회원가입 · 입력", 화면 구성은 팀 공통 규격(Banner + panel + form-grid) 기준. 현재 실제 인증 API로 동작한다 ("예시 데이터" 배지는 화면 코드 리뷰 때 정리).

| 항목 | 타입 | 범위 | 입력 위치 |
| --- | --- | --- | --- |
| 아이디 | 문자열 | 4~20자, 영문 소문자·숫자, 입력칸을 벗어나면 자동 중복 확인 | `/signup` |
| 비밀번호 | 문자열 | 8~32자, 소문자·대문자·숫자·특수문자 모두 포함, 보기 버튼 | `/signup` |
| 이름 | 문자열 | 1~50자, 문자 종류 제한 없음 | `/signup` |
| 이메일 | 문자열 | 이메일 형식, 중복 불가 | `/signup` |

결과: 가입 성공 시 로그인 화면(`/login`)으로 이동한다. 입력 오류·중복은 해당 입력칸 아래에, 네트워크 등 그 밖의 실패는 폼 아래에 표시한다.

## 로그인 화면 (`/login?next=`)

모델 화면은 아니다. 경로·입력 항목은 Figma "로그인 · 마이페이지로 이동", 화면 구성은 팀 공통 규격 기준. 현재 실제 인증 API로 동작한다 ("예시 데이터" 배지는 화면 코드 리뷰 때 정리).

| 항목 | 타입 | 범위 | 입력 위치 |
| --- | --- | --- | --- |
| 아이디 | 문자열 | 빈 값만 확인 (가입 규칙을 드러내지 않음) | `/login` |
| 비밀번호 | 문자열 | 빈 값만 확인, 보기 버튼 | `/login` |
| next | 쿼리 | 내부 경로만 허용, 외부 주소·로그인·회원가입 화면이면 홈(`/`) | 주소 |

결과: 성공하면 `next` 화면(없으면 홈)으로 이동한다. 실패하면 아이디·비밀번호 중 무엇이 틀렸는지 구분하지 않고 안내하며 비밀번호 칸을 비운다. 회원가입 직후에는 가입한 아이디를 미리 채운다. 이미 로그인한 상태로 들어오면 바로 `next`로 이동한다.

회원 전용 화면(`/mypage`, `/mypage/edit`)은 `RequireAuth`로 감싼다. 로그인 복원 중에는 확인 중 안내를 보여 주고, 로그인하지 않았으면 `/login?next=원래주소`로 보낸다. 화면 보호일 뿐이며 회원 정보는 서버가 토큰으로 다시 확인한다.

## 마이페이지 (`/mypage`)

모델 화면은 아니다. 로그인 필요(`RequireAuth`). 화면 구성은 팀 공통 규격 기준. 현재 실제 인증 API로 동작한다 ("예시 데이터" 배지는 화면 코드 리뷰 때 정리). 지금은 프로필 이미지 설정만 제공한다.

| 항목 | 타입 | 범위 | 입력 위치 |
| --- | --- | --- | --- |
| 프로필 이미지 | 파일 | JPG·PNG, 4MB 이하, 실제 파일 내용까지 확인 | `/mypage` |

결과: 고른 이미지를 미리 보여 주고, 저장하면 마이페이지에 반영된다. 이미지가 없으면 닉네임(없으면 아이디) 첫 글자로 표시한다. 규칙에 맞지 않으면 선택을 취소하고 입력칸 아래에 안내한다.

## 프로필 수정 (`/mypage/edit`)

모델 화면은 아니다. 로그인 필요(`RequireAuth`). 경로는 Figma "프로필 수정 · 기본 정보", 화면 구성은 팀 공통 규격 기준. 현재 실제 인증 API로 동작한다. 지금은 닉네임만 수정한다 (Figma의 이름·생년월일·휴대폰번호·이메일 수정은 P2).

| 항목 | 타입 | 범위 | 입력 위치 |
| --- | --- | --- | --- |
| 닉네임 | 문자열 | 앞뒤 공백 제외 2~20자, 다국어 글자·숫자·기호 허용, 보이지 않는 문자 불가, 중복 허용 | `/mypage/edit` |
| 로그인 아이디 | 표시 전용 | 바꿀 수 없음 | `/mypage/edit` |

결과: 저장하면 마이페이지로 돌아가고, 바뀐 닉네임이 프로필 이미지 대체 글자에 반영된다.

## 미결정 사항

- 서비스별 입력 항목·타입·범위
- 실제 조회와 상태 화면의 연결
- 실제 빈 결과의 조건 변경 동작
- 실제 조회 재시도 함수
- 실제 결과의 예시 표시·마스킹 적용 위치
- 회원가입: 비밀번호 확인 칸, 안내 문구, 다국어 (나중에 추가)
- 프로필 이미지: JPG 자동 변환(`prepareProfileImage`), 이미지 삭제
- 회원가입에서 `next` 이어받기 (로그인 → 회원가입 → 로그인 후 원래 화면으로)
- 대출 추천 서빙 방식 (Python 서버 / Spring에서 가중치로 직접 계산)
- 비교 라벨을 판정할 사람과 필요한 쌍의 수
- 용도 목록, 희망 금액 단위·범위, 체류기간·월소득 구간 경계, 적합도 점수 범위
- 펼친 질문을 필수로 두면서 `모름`을 허용하는 방식
- 방문을 원치 않을 때의 필터·점수 처리 방식
- 팀 ERD v2 컬럼과 정제 항목의 대응

## 주 기능 안내 화면

- 주 기능 배너 아래에 해당 기능의 세부 기능 카드를 표시한다.
- 카드 이름·설명·이동 주소는 routeConfig.js를 사용한다.
- 카드 디자인은 홈의 배경색·아이콘 영역·모서리·버튼 규격을 재사용한다.
- 기본 배치는 2열이며, 기존 홈의 작은 화면 배치 규칙을 따른다.
- 사용자는 카드의 연결 버튼을 눌러 세부 기능 화면으로 이동한다.
- 모델 입력·출력·판단 근거와의 관계는 미정이다.

## 계산기 공통 기준

- 월 상환액: `/service/monthlyPayment`
- 총 이자: `/service/totalInterest`
- 두 화면은 공통 계산 함수와 LoanCalculator 컴포넌트를 사용한다.
- 상환 방식은 입력 영역 맨 위에서 선택한다.
- 순서는 만기 일시·원리금 균등·원금 균등이며 기본값은 만기 일시다.
- 대출 기간은 거치 기간을 포함한 전체 기간이다.
- 전체 기간은 1~600개월이며 거치 기간은 전체 기간보다 짧아야 한다.
- 대출 금액은 만원 단위 정수, 연 금리는 0~20%에서 소수 한 자리까지 허용한다.
- 대출 금액은 0보다 커야 하며 기존 입력 상한을 유지한다.
- 이자는 회차 시작 잔금에 연 금리÷12를 적용하고 원 미만을 버린다.
- 마지막 회차에는 남은 원금을 정산하여 잔금을 0원으로 만든다.
- 정수 계산으로 마지막 회차의 납입액은 기준 납입액과 조금 달라질 수 있다.
- 결과 영역에는 방식 이름과 설명을 표시하며 방식 선택 버튼은 두지 않는다.
- 계산 전에는 결과·그래프·상환표를 표시하지 않는다.
- 그래프는 월별 상환금 하나만 선으로 표시한다.
- 그래프 좌표는 만원 단위이며 표와 툴팁은 정확한 원 단위 금액을 표시한다.
- 기존 입력 설명과 결과 아래 계산 기준 설명은 제거한다.
- 실제 일수·납부일·수수료를 반영하는 계산은 적용하지 않는다.

### 월 상환액 계산기

- 입력: 상환 방식, 대출 금액, 연 금리, 대출 기간, 거치 기간.
- 만기 일시에서는 거치 입력을 숨기고 0개월로 계산한다.
- 분할상환은 거치 동안 이자만 납부하고 남은 회차에 원금을 상환한다.
- 결과 순서: 첫 회차 상환 금액, 평균 상환 금액, 최대 상환 금액, 총 상환 금액.
- 평균은 전체 대출 기간 기준이며 원 미만을 버린다.
- 표 순서: 회차, 상환금, 납입 원금, 이자, 납입 원금 합계, 잔금.

### 총 이자 계산기

- 입력: 상환 방식, 대출 금액, 연 금리, 대출 기간.
- 모든 방식에서 거치 없이 계산하며 설명에서도 거치 문장을 제외한다.
- 만기 일시·원리금 균등: 매월 상환 금액, 총 상환 금액, 총 이자 금액.
- 원금 균등: 첫 달 상환 금액, 총 상환 금액, 총 이자 금액.
- 만기 일시의 매월 상환 금액은 월 이자이며 원금은 마지막 회차에 납부한다.
- 표 순서: 회차, 원금, 이자, 총 금액.

## 도움 기관 안내 — 선택 화면 초안

- 경로: `/service/consultation`
- 기존 공통 헤더·푸터·배너를 사용한다.
- 원본 초안의 상담 분야·키워드·지역·언어·상담 방식 전체를 사용한다.
- 상담 분야는 한 개, 키워드는 한 개 이상 여러 개 선택한다.
- 키워드를 다시 누르면 선택을 해제한다.
- 상담 분야 변경 시 키워드 선택을 초기화한다.
- 시·도 변경 시 시·군·구를 전체로 초기화한다.
- 부가 조건의 기본값은 전체이다.
- 필수 항목 선택 전에는 안내받기를 비활성화한다.
- 안내받기를 누르면 선택 조건만 표시한다.
- 조건을 변경하면 이전 확인 내용을 지운다.
- 실제 기관 조회·추천 근거·DB 연결·다국어 번역은 미정이다.
- 원본 지역 목록과 최신 행정구역의 일치 여부는 미확인이다.
