커뮤니티 예시 게시글 조회는 화면 확인용이며, 실제 게시글 조회 API는 미정이다.

## 공통 상태 화면

헤더·푸터 없이 공통 배경의 중앙에 아이콘과 문구를 표시한다.

- 로딩: 회전하는 모래시계와 대기 문구
- 빈 결과: 빈 목록 안내
- 실패·재시도: X 표시, 실패 안내와 재시도 버튼
- 입력 검증: 입력 항목 아래 오류 표시
- 예시 표시: 예시 데이터·예시값 배지
- 마스킹: 가상 이름·계좌번호를 일부 가려 표시
- 잘못된 접근: X 표시와 오류 문구

입력 검증 화면은 필수 입력을 확인하는 표시 초안이다.
실제 서비스 입력 항목과 검증 범위는 미정이다.

## 미결정 사항

- 서비스별 입력 항목·타입·범위
- 실제 조회와 상태 화면의 연결
- 실제 빈 결과의 조건 변경 동작
- 실제 조회 재시도 함수
- 실제 결과의 예시 표시·마스킹 적용 위치
