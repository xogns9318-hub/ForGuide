# 확인할 사항

코드와 화면에 쓴 예시값·가정을 기록한다. 출처를 확인하면 값을 고치고 줄을 지운다.

## 계좌: 외국인 가입 판정

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| "비거주 외국인 외 제한없음" | 국내 거주(등록) 외국인은 가입 가능 | 해당 저축은행 상품설명서·약관 |
| "실명의 개인" | 확인 필요 | 은행 상품설명서, 금융실명법상 외국인 실명확인 |
| 케이뱅크 예·적금 | 불일치. 근거: 뉴데일리 2026-07-23 출시 준비 기사, 2026-10-23 확인 | 케이뱅크 공식 공지 (출시되면 보정 표 수정) |
| 카카오뱅크 예·적금 | 확인 필요. 근거: 외국인통장 페이지(입출금만 안내), 2026-10-23 확인 | 카카오뱅크 예·적금 상품설명서 |

## 계좌: 계산·점수

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| 복리 주기 | 월복리 가정 (API에 주기 없음) | 각 금융사 상품설명서 |
| 자유적립식 적금 수익률 | 정액적립식과 같은 방식으로 계산 | 각 금융사 적금 상품설명서 |
| 금리 이상값 | 같은 목적·기간에서 Q3 + 1.5×IQR 초과. 이상값 상품의 가입 조건(출산, 첫 거래 등)은 확인하지 않음 | 해당 상품설명서 |
| 기준선 가중치 | 금리 0.5, 확인 필요 −0.3, 방문 −0.2, 비선호 금융기관 −0.3 (예시값) | 쌍대 비교 학습 결과 |
| 외국인의 은행 예·적금 선호 | "은행 선호"라고 답한 사람에게만 저축은행 감점(2026-10-26부터, 이전에는 모든 사용자). 은행 선호 선택지를 둔 근거: 아시아투데이 2026-08-23, 뉴시안 2025-04-12, KB의 생각(저축은행 외환 업무 제한), MDIS 2025 국외 송금 응답 약 39%(코드 1=송금함으로 추정). 직접적인 선호 조사 없음 | 외국인 금융기관 이용 실태 조사, MDIS 코드북 |
| 결과 안내 "저축은행 예·적금도 예금자보호 대상" | 보호 한도는 적지 않음 (`ko.js` `recommendResult.notices`) | 예금보험공사 예금자보호 안내 |
| fast 넣어 둘 기간 선택지 | 6 / 12 / 24 / 36개월 (원본 기간 1·3·6·12·24·36 중 적금 상품이 적은 1·3 제외). 남은 체류기간보다 길게 고르지 말라는 안내만 표시 | 외국인 체류기간 분포, 사용 로그 |

## 보험 (실손)

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| 보장 표준화 | 회사 간 보장이 같다고 보고 보험료로 비교 | 실손의료보험 표준약관 |
| 특약1·특약2 | fast는 기본형 + 특약1 + 특약2 합계로 비교 | 표준약관, 보험사 상품요약서 |
| MG손보 | 2025-01 이후 갱신이 없어 제외 | 손해보험협회 공시실 |
| 보험료 단위 | 월 보험료(원)로 추정 | 실손보험정보 API 제공기관 |
| 보험료 0 | 그 나이에 가입 불가로 보고 제외 | 손해보험협회·생명보험협회 공시 |
| 보험 나이 | 사용자의 만 나이를 공시 데이터의 나이로 그대로 씀 (공시 나이가 보험 나이인지 API 문서에 없음) | 실손보험정보 API 제공기관, 보험사 상품요약서 |
| 보험사 연락처 | 실손 데이터의 줄임 이름을 금융상품한눈에 정식 이름에 손으로 대응 (`clean_insurance.py`). 메리츠화재·한화손보·신한EZ손해보험·DB생명은 목록에 없어 비워 둠 | 각 보험사 공식 홈페이지 |
| 신한EZ손해보험 온라인 가입 | 상품명에 "다이렉트"가 없어 다이렉트 아님 | 신한EZ손해보험 상품 안내 |

## 대출

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| 용도 선택지 | 생활비 → 신용대출, 전세 보증금 → 전세자금대출 | 사용 로그 |
| 가입 대상이 정해진 상품 | 상품명에 청년·신혼·다자녀·사회초년·버팀목·디딤돌·군인·공무원·교직원·임직원이 있으면 확인 필요 맨 아래 (`clean_finlife_loans.py`) | 각 상품설명서 |
| 신용대출 평균 금리 | 공시 `crdt_grad_avg`(전월 취급 평균)를 그대로 표시 | 금융상품한눈에 항목 설명 |
| 전세 보증기관의 외국인 조건 | 확인 필요 | HF, HUG, 서울보증보험 공식 안내 |
| 용도 괄호 표기 | 전세 보증금 (담보): 전세자금대출을 보증서 담보 대출로 보고 "담보"로 표기 | 은행 전세자금대출 상품설명서 |
| 신용점수 구간 (plus) | 금리 열 `crdt_grad_1·4·5·6·10·11·12·13`을 900점 초과 ~ 300점 이하 8구간으로 대응 | 금융상품한눈에 개인신용대출 API 항목 설명 |

## 가상 사용자·판정

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| MDIS에 없는 답 (계좌 목적·기간·금융기관 선호·방문, 대출 용도) | 선택지 중 고르게 무작위 | 사용 로그, 외국인 금융이용 실태 조사 |
| 건강보험 가입·본인 명의 통장 | 전원 "예" (아니오면 모델을 거치지 않음) | 국민건강보험공단 외국인 가입 통계 |
| 나이 | MDIS 연령 구간 안에서 무작위, 15~29세는 19세부터, 60세 이상은 70세까지 | 서비스 이용 연령 확정 시 |
| 체류자격별 인원 | 최소 5명 보장, 평가 시 "현실 비율 ÷ 표본 비율"로 보정 | 평가 설계 확정 시 |
| 판정 페이지·계좌 결과 화면 이자 환산 | 예금 1,000만 원, 적금 월 50만 원, 세전, 복리는 월복리 (예시값, `frontend/src/recommend/utils/interest.js`) | 외국인 평균 저축액, 각 상품설명서 |
