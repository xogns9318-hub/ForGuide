# 확인할 사항

코드와 화면에 쓴 예시값·가정을 기록한다. 출처를 확인하면 값을 고치고 줄을 지운다.

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| 예·적금 복리 주기 | 월복리로 가정 (금융상품한눈에 API에 주기 필드 없음) | 각 금융사 상품설명서, 금융감독원 금융상품한눈에 |
| "비거주 외국인 외 제한없음" 해석 | 국내 거주(등록) 외국인은 가입 가능으로 판정 | 해당 저축은행 상품설명서·약관 |
| "실명의 개인" 가입대상의 외국인 가능 여부 | 확인 필요로 판정 | 은행 상품설명서, 금융실명법상 외국인 실명확인 방법 |
| 계좌 fast 넣어 둘 기간 선택지 | 6 / 12 / 24개월 (공시 저축 기간 중 선택, 예시값) | 외국인 체류기간 분포, 서비스 사용 로그 |
| 실손보험 보장 내용의 표준화 | 회사 간 보장이 같다고 보고 보험료로 비교 | 실손의료보험 표준약관 (금융감독원) |
| 실손 비급여 특약1·특약2의 의미 | fast 비교 시 기본형 + 특약1 + 특약2 합계로 비교 | 실손의료보험 표준약관, 보험사 상품요약서 |
| MG손보 실손 판매 여부 | 2025-01 이후 갱신이 없어 비교에서 제외 | 손해보험협회 공시실, MG손보 공지 |
| 예·적금 금리 이상값 기준 | 같은 목적·저축 기간에서 Q3 + 1.5 × IQR 초과 (일반적인 통계 관례, `clean_finlife_savings.py`). 이상값 상품의 우대·가입 조건(출산, 첫 거래 등)은 확인하지 않음 | 해당 상품설명서 |
| 자유적립식 적금의 수익률 계산 | 매달 같은 금액을 넣는 정액적립식과 같은 방식으로 계산 (`clean_finlife_savings.py`) | 각 금융사 적금 상품설명서 |
| 실손 보험료 단위 | 월 보험료(원)로 추정, API 문서에 단위 없음 | 실손보험정보 API 제공기관(손해보험협회·생명보험협회) |
| 실손 보험료 0의 의미 | 그 나이에 가입할 수 없는 것으로 보고 제외 (`clean_insurance.py`) | 손해보험협회·생명보험협회 공시 |
| 신한EZ손해보험 상품의 온라인 가입 여부 | 상품명에 "다이렉트"가 없어 다이렉트 아님(0)으로 분류 | 신한EZ손해보험 상품 안내 |
| 대출 금리점수 기준 | 그룹 최저 금리보다 3%p 높으면 0점 (설계용 임시값, `loan/baseline.py`) | 대출 채점 기준표 확정 시 결정 |
| 대출 용도 선택지 | 생활비·기타 → 신용대출, 주거(전세) → 전세자금대출 (임시) | 대출 용도 목록 확정 시 결정 |
| 전세자금대출 보증기관의 외국인 조건 | 확인 필요로 판정 | 한국주택금융공사(HF), 주택도시보증공사(HUG), 서울보증보험 공식 안내 |
| 계좌 기준선 가중치 | 금리 0.5, 확인 필요 −0.3, 방문 필요 −0.2, 비선호 금융기관 −0.2 (설계용 예시값) | 쌍대 비교 학습 결과와 비교 |
| 가상 사용자의 계좌 목적·넣어 둘 기간·금융기관 선호·방문 여부·대출 용도 | 근거 통계 없이 선택지 중 고르게 무작위 (계좌 목적은 예금·적금만, `build_virtual_users.py`) | 서비스 사용 로그 또는 외국인 금융이용 실태 조사 |
| 가상 사용자의 건강보험 가입·본인 명의 통장 여부 | 전원 "예" (관문에서 아니오면 상담 탭·첫 통장 안내로 가서 모델을 거치지 않음) | 국민건강보험공단 외국인 가입 통계 |
| 가상 사용자의 나이 | MDIS 연령 구간 안에서 정수 무작위, 15~29세는 19~29세, 60세 이상은 60~70세로 잡음 | 서비스 이용 가능 연령 확정 시 결정 |
| 가상 사용자 체류자격별 인원 | 체류자격마다 최소 5명 보장 후 나머지는 MDIS 가중 추출, 평가 시 "현실 비율 ÷ 표본 비율" 가중치로 보정 | 평가 설계 확정 시 결정 |
